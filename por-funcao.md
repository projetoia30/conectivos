# Quadro-mestre de conectivos por função

Consolidado por função textual. Cada entrada, quando possível, indica entre parênteses o autor de referência.

---

## 1. Iniciar parágrafo / introduzir tópico

| Conectivo | Uso típico |
|---|---|
| No entanto, há casos em que... | Abrir contraponto a algo dito antes |
| É a partir daí que se verifica... | Encadear consequência |
| Na lição de [autor]... | Introduzir doutrina citada |
| Como desdobramento lógico de..., temos... | Derivar novo tópico |
| Trata-se, portanto, de... | Sintetizar natureza jurídica |
| A título de exemplo,... | Introduzir exemplo |
| De acordo com o STF,... | Introduzir jurisprudência |
| Discute-se na doutrina... | Abrir controvérsia |
| Vejamos as várias correntes... | Introduzir enumeração |
| Como regra básica,... | Enunciar regra |
| Nos termos do artigo [x],... | Fundamentar em texto legal |
| Da simples leitura do art. [x], depreende-se... | Extrair conclusão do texto legal |
| Nesse contexto,... | Situar o raciocínio |
| Nessa linha de raciocínio,... | Continuar cadeia argumentativa |
| Por fim,... | Encerrar tópico |
| Em resumo: | Sintetizar |
| Em linhas conclusivas,... | Fechar seção |
| Suponhamos que... / Imaginemos que... | Propor hipótese |
| Cumpre ressaltar que... | Chamar atenção |
| Fixada a premissa de que... | Amarrar próximo passo |

## 2. Explicar / esclarecer ideia

- **isto é** — reformular
- **ou seja** — reformular
- **vale dizer** — reformular
- **em outras palavras** — parafrasear
- **em suma** — condensar
- **leia-se** — traduzir termo técnico
- **é dizer** — explicitar
- **segundo o qual** — introduzir explicação de norma/princípio
- **no sentido de** — indicar finalidade
- **In verbis:** — introduzir transcrição literal
- **Cuida-se de / Trata-se de** — definir natureza
- **Note-se que...** — chamar atenção
- **Percebe-se, com facilidade, que...** — evidenciar
- **fenômeno conhecido como...** — nomear
- **Por [x] entende-se...** — definir
- **Basta, dessa forma,...** — reduzir à essência

## 4. Argumentar / sustentar posição

- destarte

- de modo que
- razão pela qual
- daí porque / daí a
- Justamente por ser...
- Isto porque,...
- pois
- vez que / uma vez que
- tendo em vista

**Reforçar tese**
- Com efeito,...
- De fato,...
- É evidente que...
- É óbvio que...
- É imprescindível...
- É preciso que...
- Prevalece o entendimento de que...

- Parece-nos que...

- Não faz sentido, portanto, que...

**Reforçar por autoridade**

- em razão do disposto no art. [x]

**Adversativos**

- contudo

- Em sentido diverso,
- Ao contrário de...

**Concessivos**
- Não obstante
- Apesar de
- Embora
- Ainda que

- Inobstante

**Ressalvas polidas**
- Ousamos discordar.
- Data venia,

- Devemos ressaltar, entretanto, que...
- Nem toda [x] permite...
- Não é menos verdade, contudo, que...
- Há divergência no que concerne à...

**Excludentes / limitadoras**
- salvo se / salvo quando
- salvo
- tampouco
